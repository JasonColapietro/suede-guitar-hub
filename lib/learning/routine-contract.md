# Beginner A/D routine portability contract

`routine-template.json` is the portable authored contract, ID `guitar-beginner-ad`, revision 1. The ordered defaults are 60, 180, 180, 120, 60, 60, 600 seconds: 1,260 seconds / 21 minutes. The published source is linked in the JSON. Do not trim songs to reconcile the reference page’s rounded “20-minute” description.

`routine.ts` exports the durable models and pure decoder, preparation predicates, attempt checkpoints, reflection finalization, and `RoutineTimer`. The web storage key is `guitarhub.routine.v1.guitar-beginner-ad`. The user can export `{ template, progress }` JSON from the routine. No cloud sync or account identity is implied.

## Native mapping

- `RoutineState` schema version 1: template ID, planned durations per stable block ID, preparation confirmations, current session ID, and ordered session history.
- `RoutineSession`: UUID, template ID/revision, ISO creation/update/optional end timestamps, selected block ID, all seven block records. Timestamps are metadata, never elapsed-time inputs. An ended routine can contain untouched, skipped, partial and reviewed blocks.
- Each block stores the plan for its next attempt and an ordered array of attempts. Each `RoutineAttempt` has its own UUID and target duration snapshot. Preserve both the first attempt and every retry. Editing the plan cannot rewrite a previously reviewed attempt.
- Attempt statuses: `pending`, `paused`, `review` (timer reached target; reflection pending), `reviewed` (explicit learner reflection), `skipped`. Runtime `running` is intentionally absent from serialized data. Restore as paused; never add wall-clock time after suspension or reload.
- `elapsedMs` is bounded by that attempt’s `targetSeconds * 1000`. Use a monotonic foreground clock. Web samples at 250 ms, stops on visibility/pagehide/unmount, and treats a heartbeat gap over 2 seconds as interrupted, retaining only the last observed elapsed time. The UI requires an explicit resume. A native port should use its platform’s foreground and monotonic clock equivalents, with the same conservative gap behavior.
- Only the two `changes` blocks can set `completeMinute`; it requires a continuous, uninterrupted 60-second attempt whose target is unchanged after starting ending at 60,000 ms. `manualCount` remains learner-entered. Planning edits before the first timer start are allowed. Partial, paused, resumed, extended or otherwise edited-after-start attempts retain raw counts without a normalized rate. Initial shape is zero, each formed destination and strum adds one; A-first and D-first are separate blocks.
- Reflection is `practiced` or `revisit`, never lesson completion. “Practiced” requires the displayed self-check checkbox in the UI. The optional manual count is an integer from 0 through 10,000; blank stays null. Reflections are locked once saved; retry creates a new attempt.
- Preparation uses the template’s required lesson IDs and currently valid ready evidence if present. Otherwise each named preparation can be confirmed as `source: selfReported` with an ISO timestamp after instruction. Preparation can be reviewed/reset. It does not write lesson, reading quiz, microphone, or chord-skill progress.
- Original paid lesson routes remain previews/guarded. The routine remains a usable free practice companion by plainly linking to available instruction and named external JustinGuitar instruction. It does not require a purchase or claim to unlock lessons. All instruction and external links pause timing before opening a new tab.

## Deliberate UI limits

The routine embeds the existing authored A/D chord diagrams, written reminders, manual change-count entry, and the existing free TuningGuide in the tuning block. TuningGuide releases audio on visibility loss and unmount when switching blocks or ending the session. Learners are prompted to finish permission/setup before starting the manual block timer. Reference listening, small adjustments and rechecking are legitimate self-reported tuning time. Tuning checklist confirmation only displays local feedback; it does not update curriculum progress. There is no second microphone coach, background playback, or automatic chord scoring. Instruction opens separately with paused timing. Musical practice may use a learned song or an external resource; watching external instruction is excluded from routine time. Foreground elapsed time does not prove attendance, technique, pitch, or mastery.

Local history is retained without a fixed attempt cap. Storage failures leave a visible export warning and in-memory state; another browser tab changing the same routine stops the active local timer instead of combining concurrent clocks. Cross-platform import/sync is not implemented in this slice.
