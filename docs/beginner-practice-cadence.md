# Beginner practice cadence: published evidence and GuitarHub mapping

Checked 2026-09-04. This report describes current public teaching pages, not private app internals. The JustinGuitar lesson pages were read in a logged-out Chrome tab because the web text extractor returned only their titles. No account, purchase, copied recordings, or application edits were used. Community pages helped locate official lesson URLs; community advice is not evidence for the schedules below.

## 1. What the published opening sequence actually is

### JustinGuitar preparation and first lessons

The preparation module orders its six topics as: tuning → holding the instrument → fretting-finger placement → chord-box reading → holding a pick → strumming without a pick. Its displayed 41:14 is **lesson-media duration**, not a prescribed practice session. Tuning precedes the chord-playing module. [Before You Begin](https://www.justinguitar.com/modules/before-you-begin-guitar-basics)

The current first chord module presents D → A → anchor-finger movement → one-minute changes → bars/strumming on beat 1 → selecting the correct strings → finger-comfort guidance → two-chord songs → song-app help → practice routine → Practice Assistant help → readiness guidance. Instruction and recurring practice are separate stages; the routine follows the skills it uses. [Module 1 lesson sequence and routine](https://www.justinguitar.com/guitar-lessons/module-1-practice-routine-b1-116)

These are not the same modules as GuitarHub's numbered modules. GuitarHub's first three currently teach support/open strings, tuning, and notation. Much of that content corresponds to JustinGuitar's **preparation** stage.

### What the one-minute block measures

Justin separates careful chord accuracy practice from a 60-second switching exercise. Each interval concentrates on one chord pair; record the number of switches and revisit difficult pairs or pairs needed by a song. About 60 changes/minute is the longer-term exercise goal, while 30 is the early progression target. A simple countdown and written count are explicitly valid alternatives to its practice software. This is not an acoustic scoring specification. [One-minute changes](https://www.justinguitar.com/guitar-lessons/one-minute-changes-exercise-b1-110)

### Song choice and optional elements

The first song lesson provides A/D choices and encourages choosing music the learner enjoys. Slowing a song is supported; more elaborate arrangements are extensions. Several options require a capo or altered tuning, so the song must match the learner's available preparation. The companion app is an additional practice tool, not the only way to attempt a song. **Song practice itself remains part of the routine.** [First two-chord songs](https://www.justinguitar.com/guitar-lessons/super-easy-2-chord-songs-b1-114)

The anchor-finger mapping uses the public A/D lesson technique, not a newly designed system. [Anchor-finger lesson](https://www.justinguitar.com/guitar-lessons/how-to-use-anchor-fingers-b1-109) For exact instructional order, the D page places index on string 3/fret 2, then middle on string 1/fret 2, then ring on string 2/fret 3. The A page places index on string 3/fret 2, middle on string 4/fret 2, then ring on string 2/fret 2. GuitarHub's current wording lists D as index/ring/middle and A as middle/index/ring; the final positions agree, but the placement order needs aligning if these lessons are the reference. [D lesson](https://www.justinguitar.com/guitar-lessons/how-to-play-the-d-chord-b1-105), [A lesson](https://www.justinguitar.com/guitar-lessons/how-to-play-the-a-chord-b1-108)

**Necessary asset substitutions, stated plainly:** GuitarHub's own diagrams and synthesized pitch examples can replace instructional reference illustrations/sounds; they are not recordings of the reference teacher. For song work, use a complete suitable arrangement/backing available to GuitarHub, or clearly label a link to a playable external lesson as external practice. A newly authored two-chord study can serve as musical application only if labeled as a study; it does not supply the familiar-song repertoire advertised by the references. Do not display a missing backing control or claim that a pure tone represents an entire song.

The full sourced routine totals **21 suggested minutes including its tuning entry**. If a product-level 20-minute session is preferred, use **20 timed practice minutes plus untimed preparation**, as in the later published routines, and label that normalization as GuitarHub's choice. Do not squeeze the beginner's tuning into a completion deadline.

### C. Review schedule without inventing a scheduler

Use the established pattern: current technique → retained earlier technique → related musical application. Retain a short earlier block as new material enters, as the module 2/3 tables demonstrate. Let the learner choose a difficult previously practiced item for extra rehearsal and keep a direct way back to earlier songs. This does not justify an undocumented automatic spaced-repetition formula.

For the first three GuitarHub modules, tuner access remains part of preparation; uncertain open strings can be revisited through `g-l1-m1-02`; diagram mistakes route back to `g-l1-m3-01`; chord placement difficulty routes to the specific A/D step. Avoid adding all nine lessons to every day's routine. When songs are available, keep some familiar material available alongside current learning rather than marking it permanently finished.

## 4. Implementable session contract

These are GuitarHub engineering requirements needed to make the sourced routine usable, not assertions about private competitor implementations.

1. **Explicit ordered blocks:** store content reference, task kind, suggested seconds or untimed preparation, required assets, and result type. Show both the next task and its purpose. Calculate totals from the blocks.
2. **Separate instruction from recurring work:** first exposure opens the explanation and demonstrations. Repeated sessions return to the taught activity with its instructions one action away.
3. **Honest time:** count active practice, including deliberately silent fingering work; exclude permission waiting, pauses, reference-only playback, and background time. Preserve elapsed block time through pause/resume. Allow extend, repeat, skip, and finish; a skipped block is not a completed musical check.
4. **Block boundary:** stop capture/playback before changing activities. At a timing drill, restart a fresh measured take after interruption; never splice assisted or paused fragments into one full-performance result.
5. **Distinct evidence:** elapsed minutes, manual chord-change counts, visual-reading answers, independent pitch results, and self-reported comfort remain separate fields. Timers and diagram answers do not measure chord tone, fret buzz, or technique.
6. **Usable recovery:** preserve the selected lesson, block, tempo, and actual practiced duration when sound or permission fails. Offer reference listening or manual practice with correct labels. An attempt with insufficient signal does not create a pass.
7. **Proportionate readiness:** a routine can be logged without asserting mastery. The published 30-changes target belongs to the A/D switching skill; do not apply it to string identification or reading. The published longer-term 60 target is not a compulsory first-session gate.
8. **Cadence is adjustable:** the inspected Justin pages differ between daily encouragement and four weekly sessions; Yousician permits changing session goals. Offer an editable plan rather than presenting one inflexible streak requirement as universal reference behavior.
