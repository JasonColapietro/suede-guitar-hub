# Guided self-check evidence across devices

A saved learner reflection can mark a current guided concept, exercise, song or checkpoint ready when the authored lesson has no microphone practice specification and no reading quiz. Current instruction and a nonempty self-check are mandatory. Curriculum outlines remain incomplete.

The account event stays `kind: study`, `source: selfReported`, `disposition: reflection`, with `details.localSource: selfReported` and `assessment: ready`. New exports add `details.reflectionType: guidedSelfCheck`. Earlier web events without that label and native events labelled `concept` remain compatible only when the current lesson meets the same eligibility rules. Unknown labels and mixed reading, microphone, manual-count or study-take payloads cannot use this completion path. Revisit reflections remain revisit reflections.

The native `allowsGuidedSelfCheck` helper is shared by export, import and the app's enqueue callsite. Web export and import use the corresponding helper against current curriculum data. The existing lesson UI still requires its authored checkboxes and any tuning, manual-count or study prerequisites. No score, target match, tempo certification, elapsed duration or physical performance is inferred from a self-check. Original event identity, date and supplied duration remain unchanged; imported history does not become new guest practice or confer paid access.

## Behavioral contract

`contracts/learning-evidence.json` is generated by native `LearningEvidence.reflection` and `LearningEvidence.derive` using actual bundled instructions. It covers each lesson type, historical labels, microphone and reading lessons, a voice outline, raw events, overrides and mixed payloads. The fixture set is independent of the total number of published guides.

```sh
CONTRACT_WRITE=1 swift test --package-path GuitarHubCore --filter LearningEvidenceContractTests
node scripts/sync-native-learning-evidence.mjs --native=/absolute/path/to/native
node scripts/sync-native-learning-evidence.mjs --native=/absolute/path/to/native --check
```

## Separate native history follow-up

Native account history retains the original manual-count and study events, but the app currently materializes only microphone and reading records into its dedicated local history stores. Adding those two adapters is separate from reflected lesson completion. A future adapter must preserve the nested attempt identity and timestamps, validate the current lesson/asset association and required numeric/boolean fields, retain incomplete attempts as self reports, and suppress upload callbacks while importing. A blank web count has no native integer-count equivalent and must remain raw history rather than acquiring a fabricated count. Conflicting nested IDs must not silently replace existing attempts. Raw manual or study records alone must not mark a lesson ready.
